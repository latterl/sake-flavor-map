## 6. 蔵元公式サイト由来の商品・価格情報

| | |
|---|---|
| 場所 | `data/details/<都道府県>.json`、`data/kyoto_details.json` |
| 規模 | 1,054 銘柄・4,959 商品・公式価格 3,091 件（いずれも岐阜「初緑」の上流重複を除いた実数。アプリ上の表示レコードは重複ぶんを含み 4,961 商品・3,093 価格） |
| 出典 | 各蔵元の公式サイト／公式オンラインショップ。**全商品に `source` として出典 URL を記録** |
| 調査時期 | 2026 年 8 月 |

### 収集の方針

- **蔵元公式サイト・公式オンラインショップの掲載情報のみ**を採用しています。第三者の酒販店・通販モールが独自に付けた価格は採用していません（蔵元自身が出店しているモール店は公式扱いとしています。該当は岡山・三光正宗の 1 件）
- 通年（定番）商品を優先し、通年商品がない銘柄のみ季節商品を `"seasonal": true` として収載
- 容量は 720ml に最も近いものを 1 つ。1 銘柄あたり最大 8 商品
- 価格は税込／税抜の別を `price_note` に記録。明記がない場合は `null`
- 推測による補完は行っていません。読み取れなかった項目は `null` です

### 注意

- **価格は変動します。** 掲載時点の値であり、現在の価格を保証するものではありません。購入時は必ず出典 URL 先の公式情報をご確認ください
- 商品名・スペックは各蔵元の表記に従っています
- **蔵元・銘柄の紹介文（`brewery_summary` / `blurb`）は、出典 URL の内容をもとに本プロジェクトが要約したもの**です。ただし蔵の理念・社是・キャッチフレーズなど、**言い換えると意味が変わってしまう短い語句については鉤括弧「」付きの引用を含みます**（例: 佐々木酒造「この酒の風味こそ京都の味」、朝日酒造「地域とともに生きる酒蔵、酒造りの正道を歩んで。」など。全体で約 300 か所）。引用箇所を含むすべてのエントリに出典 URL（`official_url` / `sources`）を記録しています
- 蔵元のロゴ・商品画像は一切含んでいません。商品名・銘柄名の各商標は各権利者に帰属します
- 誤りを見つけた場合は Issue でご指摘ください

## 9. 上流データの既知の重複

さけのわの蔵元マスタに由来する重複です。上流に忠実であることを優先し、統合していません。

- **岐阜県「初緑」** … 高木酒造（brandId 1344）と奥飛騨酒造（brandId 3547）の 2 レコード。所在地・公式サイトが同一で、同じ蔵の改称前後と思われます。マップ上に 2 点として表示され、同じ商品 2 件が両方に現れます
- **県をまたぐ同名銘柄 5 件** … 道灌（兵庫/滋賀）・白龍（新潟/福井）・高砂（三重/静岡）・千代鶴（富山/東京）・WAKAZE（その他/東京）。このうち道灌は同一企業（太田酒造）の本社蔵と灘の千代田蔵、WAKAZE は同一ブランドの重複ですが、いずれも上流どおり別レコードとして扱っています
